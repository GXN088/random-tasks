Сохрани песню, подкаст и фильм в трёх переменных типа Media (выполнив восходящее приведение каждого из них), затем выполни нисходящее приведение каждого обратно к его фактическому типу, чтобы получить доступ к методу, который есть только у этого типа.Song(String title, String artist): play() выводит "Playing song: " + title + " by " + artist; showArtist() выводит "Artist: " + artistPodcast(String title, int episode): play() выводит "Playing podcast: " + title + " - Episode " + episode; showEpisode() выводит "Episode: " + episodeMovie(String title, int duration): play() выводит "Playing movie: " + title + " (" + duration + " min)"; showDuration() выводит "Duration: " + duration + " minutes"
